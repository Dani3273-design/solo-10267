# 打地鼠游戏 (Whack-A-Mole Game)

使用 Pygame 开发的经典打地鼠游戏。

## 游戏特色

- **6-9个随机洞口**：每次游戏开始时随机生成6-9个洞口位置
- **精美的视觉效果**：
  - 土色地面带有纹理效果
  - 洞口有泥土装饰
  - 地鼠有出现/消失的过渡动画
- **互动体验**：
  - 鼠标显示为锤子形状
  - 点击时锤子有挥动动画
  - 击中地鼠时：地鼠眼睛变成X、头上出现黄色圆圈、浮动金色星星
- **完整的游戏机制**：
  - 10秒倒计时
  - 暂停/继续功能
  - 统计打到的地鼠数量和空击次数

## 环境要求

- Python 3.9+
- Pygame 2.5.2

## 安装依赖

```bash
cd main
pip install -r requirements.txt
```

## 运行游戏

```bash
cd main
python main.py
```

## 游戏操作

1. **开始游戏**：点击"开始游戏"按钮开始游戏
2. **打地鼠**：移动鼠标控制锤子，点击屏幕挥动锤子击打地鼠
3. **暂停游戏**：点击右上角"暂停"按钮暂停游戏，点击"继续"或任意位置继续
4. **游戏结束**：10秒倒计时结束后，显示打到的地鼠数量和空击次数
5. **重新开始**：点击"重新开始"按钮开始新一轮游戏

## 代码模块说明

### main.py
游戏主入口，包含主游戏循环和状态管理。负责处理事件、更新游戏状态、渲染画面。

### game_config.py
游戏配置类，包含所有游戏参数：
- 屏幕尺寸、帧率
- 颜色定义
- 游戏时长、地鼠出现时间范围
- UI元素尺寸

### game_state.py
游戏状态管理，定义游戏界面枚举（主菜单、游戏中、游戏结束）和状态变量。

### game_objects.py
游戏对象类：
- **Hole**：洞口类，绘制椭圆形洞口和泥土装饰
- **Mole**：地鼠类，包含出现/消失动画、击中状态
- **Hammer**：锤子类，跟随鼠标移动，点击时挥动动画
- **Star**：星星类，击中地鼠时出现的浮动星星效果

### ui_components.py
UI组件：
- **TextRenderer**：文本渲染器，自动选择支持中文的字体
- **Button**：按钮类，支持悬停效果

### thread_manager.py
多线程管理器：
- 计时器线程：独立倒计时，不影响游戏流畅度
- 地鼠生成线程：独立随机生成地鼠，确保游戏流畅

## 多线程设计

游戏采用多线程设计确保操作流畅性：

1. **计时器线程** (`ThreadManager._timer_loop`)
   - 独立线程进行10秒倒计时
   - 每0.1秒更新一次时间显示
   - 暂停状态下时间停止

2. **地鼠生成线程** (`ThreadManager._mole_spawn_loop`)
   - 独立线程随机生成地鼠
   - 间隔 0.3-0.8 秒随机生成
   - 避免在主线程中使用 `time.sleep()` 导致卡顿

## 动画效果

### 地鼠出现/消失动画
- 地鼠从洞口逐渐"冒出来"
- 消失时逐渐"缩回去"
- 使用进度值控制显示高度

### 锤子挥动动画
- 点击时锤子从正常位置向下摆动
- 达到最大角度后返回原位
- 平滑的角度变化

### 击中动画
- 地鼠眼睛变成红色的"X"
- 头上出现半透明黄色圆圈
- 3个金色星星从地鼠上方升起并逐渐消失
- 动画持续0.3秒后地鼠消失

## 中文支持

游戏自动检测并选择支持中文的字体：
- macOS: PingFang.ttc, STHeiti Light.ttc
- Windows: simhei.ttf, msyh.ttc
- Linux: DroidSansFallbackFull.ttf, NotoSansCJK-Regular.ttc

如果以上字体都不可用，则使用系统默认字体。

## 注意事项

1. 确保安装了正确版本的 Pygame
2. 游戏窗口大小固定为 800x600
3. 游戏运行时鼠标指针会被隐藏，显示为锤子
4. 关闭游戏窗口或按 Ctrl+C 退出
